孩子拿 N 牌开车，能载几个同学，家里人算不算在乘客限制里？

N 牌乘客限制 · 数一数车上的人 · BC 现行规则

25 岁以下：非家人乘客最多一名，直系亲属不计入。副驾坐着合格监督人时不受此限。25 岁及以上的 N 驾驶者不受乘客限制。

  1. 合格监督人：年满 22 岁，持有效 Class 1–5 驾照、不带零酒精零药物限制（限制 55），能合法驾驶，坐在副驾驶位。
  2. 25 岁及以上的 N 驾驶者：不受乘客限制，也不用挂 N 牌。

违规载人出了事

  • 超员是违反 N 牌限制，会被开罚单；GLP 驾驶者一张罚单就可能被审记录、被禁驾。
  • 单纯违反驾照上的限制条款，按《Insurance (Vehicle) Regulation》s.55(3.1) 不算违反保险条件，保险不因此拒赔。

两处官方写法：《Get your N》写「一名乘客（不含直系亲属）」；25 岁以下变更页写「只能载一名乘客，除非全部乘客都是直系亲属」。一名同学加家人时两种写法结论不同，出门前问清 ICBC。
